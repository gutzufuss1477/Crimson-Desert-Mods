# Recipes for Crimson Desert 2.00.00

These recipes describe the final DMM-only 2.00.00 baseline.

- `alden_catalog.tsv`: exact original 379-item catalog and stock quantities.
- `mount_targets.txt`: 380 mount CharacterInfo record names.
- `healthbar.json`: confirmed Healthbar target skill/range helpers.
- `steelheart.json`: semantic Steelheart ItemInfo target.
- `input_hashes.json`: hashes of the clean vanilla files used for the 2.00.00 port.
