ALDEN SHOP DLC 17.4.1
Community validation build for Steam build 26448710
Requires the installed Charting the Unknown DLC

This variant adds 234 DLC offers to Alden's existing categories.
The game supplies the real DLC items, icons, effects, recipes and translations.
The mod changes their Copper purchase prices and adds the shop offers.

INSTALLATION
Use DMM 4.7.2 or later with support for the specified game build.
Close the game and unmount in DMM before updating.
Disable the regular Alden Shop or any local DLC preview, their price entries,
and their category ASI. Keep only one Alden variant active.
Import Alden_Shop_DLC.zip. Enable Alden Shop DLC and Alden Shop DLC - 1 Copper.
Activate the included Alden Category Tabs.asi through DMM's ASI management,
replacing the previous helper. Mount and restart the game.
If DMM does not import the ASI from the ZIP automatically, extract it and add
it through ASI management. Use the helper bundled with this exact package.

Better Inventory and Trade UI 3.3 is optional and stays a separate mod.
There are no shared game file paths with that original package.
Follow its author's installation instructions for DLC owners.
The helper uses the shared Microsoft Visual C++ v14 x64 runtime.

The 234 additions are 18 Abyss gears, 18 Abyss plans, 40 books,
19 recipes, 104 blueprints and 35 materials/ingredients. Tier II/III Abyss gears remain
outside this selection. The category labels follow the game's language.
The Original tab retains original stock, limits and unlock conditions.
Its nine overlapping items keep the existing 1 Copper price.
The 801 mod offers cost 1 Copper. Counters show catalog totals. Conditional
or sold-out Original offers may be hidden by the game.

CHANGES IN 17.4.1
Added 24 items to Materials for 1 Copper each, with stock 999 each.
Natural Pearl is explicitly required by 68 crafting/upgrade recipes in the
available data. The additional alchemy ingredients are Giant Abalone, Giant
Conch, Giant Starfish, Giant Sea Cucumber, Giant Sea Pineapple, Giant Stalked
Sea Squirt, Shocking Jellyfish Bell and Scaly-Foot Snail. Cooking ingredients are Abalone,
Clams, Conch, Mussel, Jellyfish Bell, Kelp, Red Seaweed, Seaweed and Sea Pineapple.
Added Leviakan Scale for sword refinement, plus all five ingredients for
Oongka's upgraded hand cannon: Upgraded Marni Laser Component, Smelted Iron Ore,
Dense Abyss Cell, Blended Gunpowder and Refined Platinum.
Each addition is explicitly named in a crafting, upgrade, alchemy or cooking recipe.
Normal item stack limits, knowledge requirements and crafting conditions stay intact.
All 40 DLC crafting books in the available DLC data were already present in
Books. The complete Books tab contains 111 offers. Recipe names follow the
game's translations, so many crafting books have individual book titles.
The new offers are appended. Existing purchase and stock identities stay
the same when upgrading from 17.4.0.

VALIDATION STATUS
The helper targets the currently verified Steam executable, build 26448710.
The DLC catalog was extracted from build 26361232, game 2.04.05.
The author does not own the DLC. Current DLC tables were unavailable. This package references
the installed DLC data by item ID and applies field-level price changes.
It does not transplant old DLC item tables into the current game.
Static data checks and native category/UI regression hosts pass.
A community user reported the 17.4.0 DLC shop working and noticed the missing
Natural Pearl. That is an initial shop report, not full DLC validation.
The new 17.4.1 offers still need in-game confirmation by DLC owners.

PLEASE CHECK
Use a separate save for the first run.
1. Confirm the game build and installed DLC, then mount without skipped mods.
2. Open Alden, switch every tab and buy a normal item and a DLC material.
   Natural Pearl / Naturperle is in Materials and should cost 1 Copper.
3. Buy a DLC Abyss gear such as Ashen Blitz / Aschener Blitz and a DLC
   blueprint or recipe. Check names, icons, purchase price and inventory count.
4. Check that the recipe can be learned and the gear has its normal DLC effect.
5. Close and reopen the shop, save and reload, then inspect stock and inventory.
6. If using original Better Inventory, check its inventory and trade grid too.
Report the game build, DMM version, item name and any skipped-mod message.
If the shop fails, include Alden Category Tabs.log and DMM's mount log.

This community build is for DLC owners. Keep the regular Alden release
when playing without the DLC. DMM's DLC requirement is set on both the
shop package and its price patch.
