# Crimson Desert 2.06.00 mod updates

27 November 2026 · Steam build **26949954** · EXE 1.0.0.3840 · DMM 5.3.2

The author confirmed the updated mods in game. Nexus lists the ten files below. Their published file IDs and scan hashes have been checked against the release ZIPs.

### Alden Shop

DLC 17.4.14 and No DLC 17.3.11 update category selection and 1 Copper catalog prices for 2.06.00. Both include the fix for the black screen before the main menu.

- [Alden Shop No DLC 17.3.11](https://www.nexusmods.com/crimsondesert/mods/2066?tab=files&file_id=23837)
- [Alden Shop DLC 17.4.14](https://www.nexusmods.com/crimsondesert/mods/2066?tab=files&file_id=23839)

### Mount stats and Steelheart

All Stats and Speed Only v16 update the level-5 stat display. Steelheart v12 changes the equipped stamina-regeneration buff from 4 to 20.

- [Steelheart Horseshoes v12 - 20 Stamina Regen](https://www.nexusmods.com/crimsondesert/mods/2365?tab=files&file_id=23840)
- [Mount All Stats v16 - Level 5 Display](https://www.nexusmods.com/crimsondesert/mods/2365?tab=files&file_id=23841)
- [Mount Speed Only v16 - Level 5 Display](https://www.nexusmods.com/crimsondesert/mods/2365?tab=files&file_id=23842)

### Healthbar

All three v6 variants update skill data and the compiled HUD. Classic shows one framed bar. Vanilla shows multiple framed bars. Caites shows multiple thin bars.

- [Healthbar Classic Single Target v6](https://www.nexusmods.com/crimsondesert/mods/2406?tab=files&file_id=23843)
- [Healthbar Caites Multitarget v6](https://www.nexusmods.com/crimsondesert/mods/2406?tab=files&file_id=23844)
- [Healthbar Vanilla Multitarget v6](https://www.nexusmods.com/crimsondesert/mods/2406?tab=files&file_id=23845)

### Mining Helmet

1.6.0 updates ore detection, highlighting and configurable range. This release checks the exact game executable.

- [Mining Helmet Always On 1.6.0](https://www.nexusmods.com/crimsondesert/mods/3586?tab=files&file_id=23846)

### Bank Refresh

1.4.2 updates the gold and active bond timer lookup. The two intervals can be configured separately in the included INI.

- [Bank Refresh Gold and Bonds 1.4.2](https://www.nexusmods.com/crimsondesert/mods/3669?tab=files&file_id=23847)

### Installation

Close the game and unmount. Replace the previous ZIP in DMM, enable the mod and any included ASI, mount and restart. Choose one Alden edition, one Healthbar style and one mount display variant. Steelheart is a separate equipment patch. Preserve custom Mining and Bank INI settings before updating.

The GitHub assets include the two mount ASIs, Steelheart, Mining Helmet, Bank Refresh and the optional standalone Healthbar helper. Both complete Alden editions and all three complete Healthbar variants are linked above. [Archive checksums](mods-b26949954-SHA256SUMS.txt).
