## Source and local inputs

Current native source is committed alongside its guarded profiles. Game-derived generated byte arrays, full UI, original tables, EXE and raw runtime captures stay local. The public mount regression uses semantic fixtures instead of runtime memory dumps; a guarded local generator extracts the native notification continuation from a supplied EXE.

Alden's current build generator lives beside its native source and requires local current UI/EXE plus the previous locally generated augmented UI. It fixes the two property conditions and regenerates private byte headers. Profile templates retain hashes, offsets, authored catalogs and relocation metadata, not complete game payloads. The optional 3x5 fixture is derived from current UI and does not establish support for an independently released UI mod.
