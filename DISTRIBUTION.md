# Distribution

Unofficial community mods for a legitimately installed game. Downloads and their
current installation instructions are linked from each mod's README.

This source import does not redistribute game executables, complete original or
modified game tables, game textures/meshes, save files or third-party runtime
binaries. Required game-derived build inputs stay local. A game name, credit or
project license does not grant rights to third-party content.

Keep the full licenses and provenance of dependencies. Do not replace an
unresolved detection with an unsupported claim that it is a false positive, and
do not ask users to disable antivirus or browser protection. Publishing source
does not independently certify the safety of a Nexus download.

Use narrowly scoped releases with source/version and payload hashes. Never use a
new repository or packaging change to conceal a known issue or evade moderation.
The historical cause of the account restriction has not been identified by GitHub.
