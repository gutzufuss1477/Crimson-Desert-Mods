# Security

Keep antivirus and browser protection enabled. Do not restore blocked files just
to retry them. A scanner detection is not automatically a confirmed false positive.

For a non-sensitive report include the Nexus mod/file ID, filename, SHA-256,
scanner, detection and date. Do not post credentials, private logs, dumps or saves
in public issues. Use GitHub private reporting if enabled; otherwise request a
private contact method without including sensitive details.
