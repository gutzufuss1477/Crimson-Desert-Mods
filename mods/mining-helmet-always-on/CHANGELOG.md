# Changelog

## 1.0.0 - 2026-09-24

- Initial public release for Crimson Desert 2.03.00.
- Automatically activates the native blue mining-resource highlight without requiring the Mining Helmet.
- Supports nearby ore, mine and rock nodes consistently across viewing directions.
- Keeps the green full-screen filter disabled.
- Preserves the original Mining Helmet behavior while the physical helmet is equipped.
- Uses the game's native visibility and fade distance.
- Adds a strict executable hash guard for the supported game build.
