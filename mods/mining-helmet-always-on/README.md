# Mining Helmet Always On

Automatically highlight ore and mineable rocks with any headgear. Adjustable range 10–120 (default 60), brightness and live INI reload. Keeps fast travel and character switching available. For 2.03.02.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/crimsondesert/mods/3586)
