[b]Update v17.2.1 — 4 November 2026[/b]
Fixes DMM skipping Alden's 1 Copper prices as outdated when [url=https://www.nexusmods.com/crimsondesert/mods/837]Character Creator Enhanced — Equip All Armor[/url] is enabled. Prices now target the intended item IDs and fields, so changes to armor record sizes no longer displace the price patches.
All 567 items and 706 price changes retain their previous effect. The catalog, stock, languages, category UI and included ASI are unchanged from v17.2. The helper still reports version 17.2 because it is byte-identical.
The author confirmed Alden, Steelheart v10, original Character Creator Enhanced 9.1.32 / Equip All Armor and original Better Inventory 3.3 together in DMM and in game on 4 November 2026 without errors. The third-party mods stay separate and unchanged. No combined package or additional compatibility patch is required.
The v17.2 runtime category system continues to avoid shared UI file replacements with Better Inventory. The single-step keyboard/Xbox tab fix is retained.
[b]Completely replace the old Alden package and enable its price patch and included category ASI.[/b] Remove old test versions and duplicate price patches. Keep only one Alden data mod and one helper active.
For [b]Crimson Desert 2.04.05 / Steam build 26361232[/b]. DLC installations/data remain unverified; no DLC-exclusive items are added.

[b]Abyss Gear tiers[/b]
Tiered Abyss Gear is deliberately sold at [b]Tier I[/b]. Tier II and III, including Vitality II/III, are not sold: you can still craft/synthesize the higher tiers yourself. This update does not change that progression choice.

Tab counts show catalog size, not remaining stock. Click a tab or use the game's displayed left/right tab controls. Reopening the shop returns to All. Other merchants do not receive this category bar.

[b]Automatic tab language[/b]
The tab labels follow your game's text language. All 15 variants are included: English, German, French, Italian, Spanish (Spain/Latin America), Portuguese (Brazil), Polish, Russian, Turkish, Arabic, Japanese, Korean and Simplified/Traditional Chinese. Custom category labels are mod translations.
Tab widths follow the text. Longer translations can wrap onto a second row above the item list. English localization and wrapping were confirmed in game; all language files passed data validation.

[b]Requirements[/b]
Windows PC, [b]Crimson Desert 2.04.05 / Steam build 26361232[/b], and [b]DMM with its ASI loader enabled[/b]. Tested with DMM 4.6.4. Install both the data mod and the included [b]Alden Category Tabs.asi[/b] helper.

[b]Install / update[/b]
[list=1]
[*]Close the game and unmount in DMM.
[*]Completely replace previous Alden shop packages, including test builds. Remove the old mod entry/folder through DMM instead of merging into it, so obsolete UI files are not retained.
[*]Import [b]Alden_Shop.zip[/b] and enable both [b]Alden Shop[/b] and [b]Alden Shop - 1 Copper[/b].
[*]Import/replace and enable the included [b]Alden Category Tabs.asi[/b] in DMM's ASI Mods section. Use the helper supplied with this package.
[*]Mount, restart the game and visit Alden.
[/list]
Do not manually copy the ZIP's internal files/ folder into the game. Only one Alden data mod and one Alden Category Tabs helper should be active.

[b]Compatibility[/b]
[list]
[*][b]Better Inventory and Trade UI 3.3:[/b] optional and installed separately from its original page. Follow its author's installation instructions, including the DLC-specific texture instructions. Alden bundles no Better Inventory assets and replaces no inventory textures.
[*][b]Load order:[/b] Alden v17.2.1 and original Better Inventory 3.3 have no shared replacement paths, so neither overwrites the other's files. No compatibility patch or combined package is required.
[*][b]Character Creator Enhanced 9.1.32 / Equip All Armor:[/b] optional and installed separately. Alden's field-level prices preserve its armor changes in either application order. No Character Creator assets are bundled.
[*][b]Without Better Inventory:[/b] the native two-column/four-row buy grid remains. With Better Inventory, its three-column/five-row buy grid remains.
[*][b]Other mods:[/b] Alden still replaces shop/data and localization files. Other Alden/shop data, item-price or LocalStringInfo replacements may conflict. Support for unrelated shop UI replacements is not established.
[*][b]Validation:[/b] Alden, Steelheart v10, original Character Creator / Equip All Armor and Better Inventory were confirmed together in game without DLC. Alden alone and reversed load order passed technical checks but have no separate gameplay confirmation. DLC installations/data tables are unverified.
[/list]
All other merchant records are preserved. The category helper targets the stated executable build and recognized buy UI; future game/UI updates may require a mod update.

[b]Uninstall[/b]
Close the game, unmount, disable Alden Shop, its price patch [b]and[/b] Alden Category Tabs ASI, then remount the remaining mods. Purchased items and spent money are not rolled back. Older files remain archived for their labelled game versions.
