# Bank Refresh Save Patcher

An external save helper that brings the next bank refresh forward after reloading a patched save. Select a slot or the newest save; a backup is created before each patch.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/crimsondesert/mods/2347)
