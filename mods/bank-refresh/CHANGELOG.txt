Bank Refresh 1.1.0 - 2026-10-09
Crimson Desert 2.03.02 / Steam build 25474236

- Added configurable bond-investment deadlines in a separate [Bonds] INI section.
- Regular gold bank and bonds can each be enabled and configured independently.
- Default: 15 in-game minutes for both. Gold range: 1..4320; bonds: 1..10080.
- Bond investments still require a MANUAL start after each completed investment.
- No automatic reinvestment, payout changes or direct balance editing.
- Existing INIs without [Bonds] keep the previous gold-only behavior.
- Preserved calendar-aware timing, native completion and exact-build guards.
- No runtime logging. Production filenames replace the local bonds-test names.
- User confirmed the bond countdown dropped from several days to 15 game minutes
  and accepted the intended manual-start behavior in-game.
- Passed 24,565 core checks, 284 host hook checks, 33 startup guard cases and
  two no-log production load tests. Final release metadata/package rebuilt.

UPGRADING: Disable/remove older Bank Refresh ASIs, including BR04 and

updated INI, or add [Bonds] manually to your existing INI. Back up saves first.

Bank Refresh 1.0.0
Crimson Desert 2.03.02 / Steam build 25474236

- First public package based on the in-game tested Bank Refresh prototype.
- Configure the refresh deadline in in-game minutes through Bank_Refresh.ini.
- Default interval: 15 in-game minutes. Range: 1 to 4320 whole minutes.
- Day/night and midnight-aware calendar conversion.
- Native bank update logic is preserved; no guaranteed profits or forced payouts.
- Strict EXE hash, function signature, caller, bank identity and memory guards.
- English configuration and documentation.
- Removed diagnostic logging, logging queue and heartbeat worker loop.
- No diagnostic setting or runtime test export in the public interface.
- Native check frequency and the temporary "Updating" message are unchanged.

Validation: development build confirmed in-game with changing gold bars and a
custom 15-minute countdown. Final log-free release compiled and offline-tested;
no separate in-game session of this exact release binary has been claimed.
