[b]Install either mount ASI through DMM[/b]
Close the game and remove older AllStats/Speed ASIs, including manual copies. Import the complete v13 ZIP under [url=https://www.nexusmods.com/crimsondesert/mods/633]DMM[/url]'s ASI Mods, enable it and mount. DMM 4.6.4 import/deployment was verified with All Stats. Both mount ZIPs use the same simple ASI-only layout; neither needs an INI. Keep DMMRuntime.asi and the existing ASI loader.
Manual alternative: copy either AllMountsLvL5AllStats.asi or AllMountsLvL5Speed.asi into bin64 beside CrimsonDesert.exe using an [url=https://github.com/ThirteenAG/Ultimate-ASI-Loader]x64 ASI loader[/url] (not included). Neither mount ASI requires DMM or Steelheart. Do not keep duplicate copies.

[b]Future game updates - both mount ASIs v13[/b]
The ASI now finds validated code structures instead of relying on fixed addresses or one executable hash. It may keep working after game updates that only move code. Changed code/layouts or ambiguous matches are refused before hooks are installed. Future compatibility is not guaranteed.
This applies to both new mount ASIs, All Stats and Speed Only. It does not make Steelheart's data patch update-independent.

[b]Install Steelheart[/b]
Close the game and unmount in DMM 4.6.4 or later. Replace/disable the old Steelheart patch, import [b]Steelheart_Horseshoes.zip[/b], enable [b]Steelheart Horseshoes - 20 Stamina Regen[/b] and mount. Restart and equip the horseshoes. Keep only one Steelheart patch enabled. Alden, Character Creator and either mount ASI are optional. Other mods changing the same stamina-regeneration buff may still conflict.

[b]Validation and uninstall[/b]
Each mount variant passed 1,135 host checks and structural/code checks against the current executable. All Stats is gameplay-confirmed; Speed Only shares its runtime except for the speed-only filter and status filename, but has not been separately gameplay-tested on this build. Both release binaries are unchanged from their validated candidates. Startup status: %LOCALAPPDATA%&#92;CrimsonDesertMods&#92;Mount_AllStats.status.txt or Mount_Speed.status.txt.
To uninstall, close the game and disable/remove the relevant mod in DMM, then remount your remaining mods. Remove a manually installed ASI manually if applicable.
