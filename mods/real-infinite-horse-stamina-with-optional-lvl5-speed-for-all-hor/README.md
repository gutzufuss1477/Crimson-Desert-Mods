# Real infinite Horse Stamina with optional LvL5 Speed for all Horses

Boost Steelheart Horseshoes stamina regeneration to +20/sec, or choose a Level 5 mount speed/all-stats package. Mount packages support 2.03.02; use only one of the two mount variants.

[Current downloads and installation instructions on Nexus Mods](https://www.nexusmods.com/crimsondesert/mods/2365)
