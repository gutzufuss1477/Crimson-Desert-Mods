# Local DMM overlay tooling

This is the original shared table/parser and transformation tooling, retaining
its scoped license. Its historical default is 2.00.00; it is not presented as an
exact rebuild of the current 2.01.00 overlays. The exact currently published
declarative manifests are stored with the corresponding mods. Full game tables,
UI originals and build inputs must remain local. Do not publish a generated
overlay until the target game version, transformation and distribution rights
have been checked. Native 2.03.02 plugins have their own source/build directories.
